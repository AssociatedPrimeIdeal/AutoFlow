# Python API parameters

Every `AutoFlowConfig` field. **Class defaults** below apply to a direct `AutoFlowConfig()` call; `from_config_dir()` loads [JSON defaults](parameters.md) first and then applies keyword overrides. For function signatures and return values, see [Python API](python-api.md).

| `config_dir` | Optional[str] | `null` | `AutoFlowConfig` | Directory containing module JSON defaults. None resolves installed/repository defaults; explicit AutoFlowConfig fields override bundle-mapped fields. | `autoflow/processing.py` |
