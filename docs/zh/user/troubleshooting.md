# 故障排查

## GUI 启动失败

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示 GUI 依赖未安装 | 没装 GUI extras | 执行 `pip install -e ".[gui]"` |
| `PyQt5`、`vtk`、`pyvistaqt` 导入失败 | 环境里缺 GUI 依赖 | 在同一环境补装 GUI 依赖 |

## 依赖分割的步骤被跳过

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| skeleton、graph、planes、metrics 被跳过 | 没有活动分割 | 先加载、导入、阈值化或自动分割 |
| CLI 自动跳过依赖分割步骤 | 输入没有分割且没启用 `--autoseg` | 重新运行并加 `--autoseg` |

## 自动分割失败

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 提示缺少 `mag` 或 `flow` | 输入不是支持自动分割的标准化数据 | 换成有 `mag` 和 `flow` 的输入 |
| 提示模型目录缺失 | 没有显式模型且仓库默认模型不存在 | 设置 `--autoseg-model` 或在 GUI 里配置模型路径 |
| nnUNet 子进程失败 | nnUNet 未安装、checkpoint 错、模型目录错 | 检查 nnUNet 安装和模型目录 |

## TKE 缺失

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 看不到 TKE 视图或视频 | 输入本身没有 TKE 支持 | 这是预期行为 |
