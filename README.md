## Install

### Windows

[Download AutoFlow](https://github.com/AssociatedPrimeIdeal/AutoFlow/releases)

### Python

With Python 3.11:

```bash
git clone --recurse-submodules https://github.com/AssociatedPrimeIdeal/AutoFlow.git
cd AutoFlow
pip install -e ".[all]"
autoflow-gui
```
